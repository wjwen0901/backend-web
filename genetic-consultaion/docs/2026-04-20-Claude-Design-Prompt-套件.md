## Prompt 1：设计系统总控

```text

- 项目路径：/Users/wjwen/git/mdhcare/gensultation-web/genetic-consultaion
- 技术栈：Vue 2 + Element UI + 现有路由/接口/业务逻辑
- 这是一个医疗/基因检测相关的后台管理系统
- 本轮只聚焦后台管理端 src/views/home/**
- 暂时不要扩展到 wechat/H5 端
- 目标不是“炫酷改版”，而是建立统一、专业、有高级感、可推广的后台设计系统

已经确认的设计方向：
- 风格方向：Premium Clinical
- 品牌感强度：中等品牌感
- 视觉目标：高级、洁净、可信，不要做成普通 Element 后台，也不要做成泛互联网 SaaS 风
- 信息密度：中高密度
- 优先级：统一感 > 单页炫技
- 技术约束：严格保留 Vue 2 + Element UI + 现有路由/接口，不升级框架，不迁移到 Vue 3/React/Tailwind，不重写业务逻辑
- 主色可以参考现有主题色 #14a495，但不要只停留在“换主色”

请先分析这些页面与文件：
- src/views/home/home.vue
- src/views/home/dashboard/dashboard.vue
- src/views/home/order/order.vue
- src/views/home/report/report_upload.vue
- src/App.vue
- src/element-variables.scss

你的任务：
1. 先做当前 UI 的问题诊断，重点找“缺少统一感”的根源
2. 基于 Premium Clinical 方向，输出一套后台设计系统方案
3. 明确设计系统如何覆盖这些核心场景：
   - 导航框架
   - 页面标题区 / breadcrumb / toolbar
   - 数据卡片 / dashboard 模块
   - 筛选区 / 搜索区
   - 表格 / 批量操作 / 分页
   - 表单分组 / 上传区 / 操作按钮
   - 标签 / 状态 / 空状态 / loading / 弹窗
4. 给出具体设计 token 建议：
   - 色板
   - 字体层级
   - 间距体系
   - 圆角
   - 阴影
   - 边框
   - 状态色
5. 给出页面骨架建议：
   - home.vue 的整体导航框架如何统一
   - dashboard.vue 如何从旧式卡片升级为更有秩序的运营首页
   - order.vue 如何变成更专业的高密度列表页
   - report_upload.vue 如何变成可信、清晰、易操作的复杂上传表单
6. 给出“可在现有技术栈内落地”的实现建议，不要脱离 Element UI 生态
7. 输出一个样板页改造优先级与实施顺序

输出要求：
- 不要直接全站开改
- 不要给我 3 套完全不同的风格方向，直接围绕 Premium Clinical 深挖
- 不要写成空泛的品牌描述
- 请用“诊断 -> 设计系统 -> 页面策略 -> 落地建议”的结构输出
- 如果你认为某些页面需要调整布局结构，可以提，但不要改变核心业务流程
```
